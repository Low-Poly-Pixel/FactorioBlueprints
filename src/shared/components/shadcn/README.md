# shadcn/ui — generated, not hand-authored

Everything in this folder is dropped in verbatim by the shadcn CLI (`npx shadcn add <name>`), not written by hand. That's why it looks different from the rest of this repo: `function` declarations instead of arrow functions, no inline prop types, etc. — none of the style rules in the root `CLAUDE.md` apply here. Don't "fix" these files to match the rest of the codebase; regenerating via the CLI would just undo it.

Adding a new one keeps working as normal — `components.json`'s `ui` alias points here.
